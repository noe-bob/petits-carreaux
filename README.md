# Petits Carreaux

Application personnelle : tâches, agenda et idées de vidéos.
Un seul fichier, `index.html`, sans dépendance à installer.

Les données sont pour l'instant enregistrées dans le navigateur de chaque
appareil. La synchronisation entre appareils est en cours d'ajout.

Aucune donnée personnelle n'est publiée dans ce dépôt.
